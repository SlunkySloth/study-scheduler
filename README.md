# Study Scheduler

My personal daily planner for the SDE + ML internship plan: what to do right now, a focus timer, streaks, roadmap checklist, application tracker, AWS practice-exam tracker, weekly report and badges.

- Hosted on GitHub Pages; data is stored in Firebase Firestore under my Google account (see `firestore.rules`).
- `jobs.json` is updated every morning by my local Job Watcher script.
